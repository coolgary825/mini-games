# 믹스 히어로즈

갑옷 기사와 레인저를 지휘하는 캐주얼 자동 전투 게임입니다. 코인으로 가디언·레인저를 부르고, 기본 무기를 합성하고, 여섯 자리에 팀을 배치해 열 번의 전투 동안 방어 코어를 지킵니다. 각진 갑옷 캐릭터·골렘 SVG와 돌 성채 Canvas 전장, Web Audio 효과음을 직접 제작했으며 외부 이미지·폰트·라이브러리·서버 API 없이 실행됩니다.

## 실행과 배포

저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000/mix-heroes/`를 엽니다. 빌드 단계는 없습니다. GitHub Pages의 main 브랜치 루트 배포를 사용하며 모든 경로는 상대 경로입니다.

공개 경로: https://coolgary825.github.io/mini-games/mix-heroes/

## 플레이

1. 팀 탭의 ‘모집’로 근거리 가디언(50코인) 또는 원거리 레인저(60코인)를 구매합니다. 기본 무기를 가지고 추천 자리에 합류합니다.
2. 가방의 무기 두 개를 고르면 합성 결과를 미리 볼 수 있습니다. ‘합성하기’를 눌러야 재료가 소비됩니다. 합성은 무료이며 항상 성공합니다.
3. 장착할 용사를 고른 뒤 ‘무기 바꾸기’를 누르고 가방의 무기를 선택하면 바로 장착합니다. 이 창에는 역할에 맞는 무기만 표시됩니다. 기존처럼 가방에서 무기 하나를 선택하고 ‘장착하기’를 눌러도 됩니다. 교체한 무기는 가방으로 돌아갑니다. 같은 종류의 기본 무기도 합성하면 강화됩니다.
4. 전장이나 우리 팀 목록에서 친구를 고릅니다. ‘자리 옮기기’ 후 지도에서 자리를 누르면 이동하거나 두 친구의 자리를 교환합니다. 빈자리는 직접 눌러 이동할 수도 있습니다.
5. ‘전투 시작’으로 자동 전투를 시작합니다. 전투 중에는 구매·배치·합성·장착이 잠깁니다. 1×/2×, 멈춤, 음소거를 사용할 수 있습니다. 다음 웨이브는 자동 시작하지 않습니다.

| 합성 | 무기 | 장착 | 효과 |
| --- | --- | --- | --- |
| 나무검 + 별지팡이 | 불꽃검 | 가디언 | 3초 동안 주기적인 화상 피해 |
| 새싹활 + 별지팡이 | 얼음활 | 레인저 | 2초 동안 이동 속도 감소 |
| 돌망치 + 별지팡이 | 번개망치 | 가디언 | 가까이 모인 적에게 범위 피해 |
| 나무검 + 새싹활 | 바람활 | 레인저 | 가까운 두 번째 적까지 한 번 관통 |
| 같은 기본 무기 2개 | 튼튼한 무기 | 원래 역할 | 공격 힘 증가 |

합성 무기는 다시 합성하지 않습니다. 가방은 20칸, 팀은 6명입니다. 쓰러진 친구와 보석 체력은 다음 웨이브에 회복합니다. 패배 시 또는 전투 도중 새로고침 시 준비가 끝난 전투 직전 상태로 복구합니다. 이미 얻은 전투 보상을 다시 받는 방식의 복제는 방지합니다. 최종 승리 후에도 모집·합성·배치·장착을 할 수 있습니다. 전투와 보상은 다시 시작되지 않으며, 새 모험은 별도로 시작합니다.

모바일 하단의 전투·팀·무기 탭은 한 화면씩 표시합니다. 전투가 기본 화면이며 시작 버튼이 첫 화면 안에 보입니다. 팀에서 모집·자리 이동을 하고, 무기 탭에서 장착 대상 선택·재료 구매·합성·장착을 이어서 합니다. 준비 안내와 자리 이동은 해당 탭으로 연결됩니다. 데스크톱에서는 전장·팀·무기를 함께 표시합니다. 모든 기능은 클릭·탭으로 조작하며 드래그는 필요 없습니다. PC에서는 다른 버튼에 초점이 없는 경우 Space로 시작/일시정지할 수 있습니다. 다른 탭으로 이동하거나 도움말을 열면 전투가 멈춥니다.

## 저장과 접근성

전용 저장 키는 `junwoo-mix-heroes-v1`입니다. 다른 게임 저장 키는 읽거나 변경하지 않습니다. 잘못된 저장은 초기 상태로 복구하고, 저장이 막힌 브라우저에서도 현재 화면의 플레이는 가능합니다. 저장 실패는 화면 하단에 표시합니다. 소리는 처음에 꺼져 있으며 사용자 입력 후에만 재생됩니다. 감소된 모션 설정을 존중하고 버튼 이름, 상태 알림, 키보드 포커스, 기본 dialog를 제공합니다.

외부 자산은 없지만 PWA 오프라인 설치나 여러 기기 간 동기화는 포함하지 않습니다. 기기별로 진행이 저장됩니다.

## 파일

- `data.mjs`: 공격수, 무기 12종, 조합 8종, 적 4종, 10개 웨이브 데이터.
- `engine.mjs`: 경제·장착·배치·전투·피해 효과·체크포인트·저장 검증. DOM 없이 실행됩니다.
- `art.mjs`, `render.mjs`: SVG 원화와 애니메이션, 전장 배경 캐시, 이펙트.
- `game.mjs`: 화면, 입력, 효과음, 모달, 진행 저장.
- `index.html`, `style.css`: 반응형 화면과 접근성 구성.

## 검증

```sh
node --test mix-heroes/tests/engine.test.mjs
```

두 조합 전략 × 두 속도의 10웨이브 완주, 모든 합성 조합, 역할 제한, 재료 보존, 배치 교환, 상점 제한, 네 가지 실제 특수 효과, 패배·재시도·재접속·보상 중복 방지와 잘못된 저장을 확인합니다. 강화하지 않은 팀은 마지막 보스에 패배하고, 준비된 서로 다른 팀은 완주하도록 검증합니다.

크롬과 Playwright가 있는 환경에서 브라우저 검증:

```sh
MIX_URL=http://localhost:8000/mix-heroes/ \
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
node mix-heroes/tests/browser.mjs
```

실제 UI로 구매·합성·장착·배치·일시정지·저장 복구, PC 10웨이브, 터치 첫 웨이브·최종 보스, 모바일 탭 전환·첫 화면의 시작 버튼·작은 화면, 모달, 저장 차단, 기존 게임 저장 유지와 자산 오류를 확인합니다. 테스트만 가상 시계를 사용하며 게임 실행 코드에는 자동 플레이가 포함되지 않습니다.

장착 대상은 합성 후에도 유지됩니다(완성 무기와 역할이 다를 때만 맞는 용사로 바꿉니다). 장착 버튼·알림에 용사 번호를 표시하고 대상 목록에 현재 무기를 표시합니다. 완성 무기는 합성 재료로 함께 선택하지 않고 장착용으로 하나만 선택합니다.

장착 회귀 검사: `PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node mix-heroes/tests/equipment.browser.mjs`. 가디언 두 명의 개별 합성·장착·교체·저장 유지를 PC와 모바일에서 확인합니다.

클리어 저장 장착 검사: `PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node mix-heroes/tests/equipment-completed.browser.mjs`. 10단계 완료 상태·재료 두 개 선택 상태에서 가디언을 지정해 직접 교체하고, 역할 제한·가방 반환·재접속·빈 가방 안내·다음 준비 시 잠금 해제를 PC와 터치에서 확인합니다.

활·지팡이는 레인저, 검·망치는 가디언 전용입니다. 가방에서 무기 하나를 선택했을 때 현재 용사의 역할과 맞지 않으면 보유한 같은 역할의 용사를 선택합니다. 레인저가 없으면 모집 화면으로 안내합니다. 역할별 여섯 원거리 무기는 `tests/equipment-roles.browser.mjs`에서 검사합니다.

# 알까기 클럽

외부 라이브러리 없이 Canvas와 JavaScript로 만든 1인용 알까기입니다.
`index.html`을 브라우저에서 열거나 게임천국 첫 화면의 알까기 카드를 선택하세요.

- 검은 돌 5개 대 흰 돌 5개. 검은 돌이 먼저 시작하고, 모든 돌이 멈추면 차례가 바뀝니다.
- 내 돌을 누르고 발사 방향 반대로 당겼다 놓습니다. 최대 힘은 보드 좌표 기준 190px 드래그입니다.
- 마우스와 터치를 지원합니다. Esc, 우클릭 또는 터치 취소로 조준을 취소할 수 있습니다.
- 키보드: 보드에 포커스 → 좌우로 돌 선택 → Enter로 조준 → 좌우로 각도, 위아래로 힘 → Enter 발사.
- 돌 중심이 보드 안쪽 점선 경계를 넘으면 탈락합니다. 양쪽 마지막 돌이 같은 샷에서 떨어지면 무승부입니다.
- 7단계 모두 자유롭게 선택할 수 있습니다. 난이도 선택 또는 ‘다시 한 판’은 즉시 새 게임을 시작합니다.
- 승리 횟수, 선택한 난이도, 소리 설정은 이 브라우저에 저장됩니다. 저장 기능이 차단되어도 플레이할 수 있습니다.

AI는 실제 게임과 같은 물리 엔진으로 후보 샷을 시뮬레이션합니다. 난이도에 따라 후보 수와 오차가 달라지고,
상위 단계는 자기 돌 보존, 최종 배치, 마지막 단계는 상대의 반격 한 수까지 평가합니다.
양쪽 돌의 크기·마찰·최대 힘은 동일합니다. 최상위 AI도 제한된 후보를 탐색하므로 완벽한 플레이를 보장하지 않습니다.

검증: `node --test alkagi/physics.test.cjs` (게임천국 저장소 루트에서 실행).

# 집으로 가는 길 · 우리집 구조대

준우(5학년), 은우(3학년), 리우(1학년)와 함께 라떼, 모카, 커피, 여름, 가을을 안전하게 집으로 안내하는 10단계 2D 퍼즐 게임입니다. 브라우저 기본 기능과 직접 만든 SVG 일러스트만 사용하며 외부 라이브러리·폰트·이미지·서버 API가 필요 없습니다.

## 실행

`mini-games` 폴더에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000/rescue/>를 엽니다. ES 모듈을 사용하므로 HTML 파일 더블클릭 대신 HTTP 서버로 실행하세요. 빌드나 패키지 설치는 필요 없습니다.

## GitHub Pages

이 저장소의 Pages는 현재 `main` 브랜치의 `/` 폴더를 배포하도록 설정되어 있습니다. `rescue/` 폴더와 게임 목록의 `index.html` 변경을 검토한 뒤 `main`에 반영하면 됩니다. 추가 Actions 워크플로는 필요 없습니다.

배포 후 게임 경로: `https://coolgary825.github.io/mini-games/rescue/`

다른 저장소에서는 Settings → Pages → Deploy from a branch → 배포 브랜치 → `/ (root)`를 선택합니다. 모든 리소스는 상대 경로이므로 `/저장소이름/rescue/`에서도 동작합니다. `rescue/`의 게임 파일을 모두 포함하세요. 루트에는 기존 `.nojekyll`이 있습니다.

## 게임 방법

1. 구조 가방에서 필요한 도구를 고릅니다. 다리·표지판·쿠션으로 시작하고 6단계부터 계단, 7단계부터 바닥 뚫기가 추가됩니다.
2. 지도에서 같은 모양의 점선을 눌러 설치합니다.
3. 출발을 누르면 동물들이 자동으로 걷습니다. 걸어가는 중에도 설치할 수 있습니다.
4. 높은 낙차에는 쿠션, 반대 방향으로 걷는 동물에게는 표지판, 끊어진 길에는 다리가 필요합니다.
5. 계단으로 높은 길에 올라갑니다. 바닥 뚫기는 표시된 위층 바닥을 제거해 아래층으로 통로를 엽니다. 먼저 아래에 땅과 쿠션이 있는지 확인하세요.

실수하면 출발점으로 안전하게 돌아갑니다. 일시정지, 속도 1×/2×, 도구 되돌리기, 다시 시작을 언제든 사용할 수 있습니다. 모든 스테이지를 자유롭게 선택할 수 있습니다.

PC 단축키: `1` 다리, `2` 표지판, `3` 쿠션, `4` 계단, `5` 바닥 뚫기, `Space` 출발/멈춤(버튼에 초점이 있으면 해당 버튼 실행), `Ctrl/Cmd + Z` 마지막 도구 되돌리기. 모바일에서는 지도를 옆으로 밀어 살펴보며, 도구 선택 시 설치 위치를 보여 줍니다. 출발하면 동물을 따라갑니다.

## 6~10단계

| 단계 | 모험 | 새 도전 |
| --- | --- | --- |
| 6 | 한 계단 더 가까이 | 계단으로 언덕에 오른 뒤 다리로 건너기 |
| 7 | 아래층의 비밀 통로 | 위층 바닥을 뚫고 쿠션으로 착지하기 |
| 8 | 두 번 오르면 꽃동산 | 방향 전환, 계단 두 개, 다리를 연결하기 |
| 9 | 어디를 뚫어야 할까? | 두 바닥 중 아래 길이 있는 곳을 골라 뚫기 |
| 10 | 우리 모두의 큰 모험 | 다섯 도구를 모두 조합해 다섯 마리 구조하기 |

9~10단계에는 바닥 뚫기 도구가 하나뿐이고 후보 위치는 두 곳입니다. 잘못 선택해도 안전하게 출발점으로 복귀하며, 되돌리기로 구멍을 메우고 도구를 돌려받을 수 있습니다. `힌트`는 잘못 연 통로를 알려 줍니다. 기존 1~5단계의 저장 기록과 소리 설정은 같은 저장 키를 사용하므로 유지됩니다.

첫 실행은 음소거 상태이며 상단 소리 버튼을 누르면 효과음이 켜집니다. 음소거 설정, 마지막 스테이지, 구조 완료 기록은 `localStorage`의 `our-little-rescue-v1`에 저장합니다. 브라우저가 저장을 제한해도 현재 게임은 플레이할 수 있습니다. 탭을 떠나면 자동으로 일시정지합니다.

## 수정할 곳

| 파일 | 내용 |
| --- | --- |
| `data.mjs` | 가족 이름·학년, 반려동물 털색·나이, 스테이지 지형·도구·대사 |
| `art.mjs` | 캐릭터, 나무, 집, 다리 등 SVG 일러스트 |
| `style.css` | 화면 배치·색상·모바일 스타일·애니메이션 |
| `engine.mjs` | 이동·중력·착지·방향 전환·구조·되돌리기 규칙 |
| `terrain.mjs` | 바닥의 구멍과 계단 단차: 화면과 충돌 판정이 함께 사용하는 지형 |
| `game.mjs` | 화면 갱신·입력·효과음·진행 저장 |
| `index.html` | 화면 구조와 도움말 |

여름은 크림색, 가을은 갈색으로 임시 디자인했습니다. 아이들의 헤어스타일과 의상도 임시 일러스트입니다. `data.mjs`의 색상과 `art.mjs`의 모양을 교체할 수 있습니다. 미디어를 외부에서 가져오지 않으므로 현재 버전은 네트워크 연결 없이도 로컬 HTTP 서버에서 실행할 수 있습니다. 서비스워커 기반 오프라인 설치 기능은 포함하지 않습니다.

## 검증

```sh
node --test rescue/tests/engine.test.mjs
```

10개 스테이지의 전체 동물 구조, 도구 하나씩 누락했을 때의 안전한 복귀와 복구, 일시정지, 2배속, 수량 및 되돌리기, 이동 중 다리·계단 제거 후 복구를 검사합니다. 추가로 실제 계단 상승·구멍 통과, 잘못된 바닥 선택 후 재도전, 위층만 뚫리는 지형과 복원, 높은 벽 충돌을 검사합니다.

브라우저 통합 검사는 Playwright를 사용할 수 있는 환경에서 다음과 같이 실행합니다. 기본 URL은 저장소 상위 폴더에서 `python3 -m http.server 8765 --bind 127.0.0.1`로 제공하는 `/mini-games/rescue/`입니다.

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node rescue/tests/browser.mjs
```

다른 서버를 사용하면 `RESCUE_URL`로 URL을 지정하세요. 브라우저 검사는 독립된 Chrome 세션에서 PC의 10개 단계, 모바일의 6~10단계, 구조 완료 화면, 예전 5단계 저장 기록 호환, 새 도구 단축키, 잘못된 구멍 힌트와 복원, 잘못된 저장 데이터, 하위 경로 리소스 로딩을 확인합니다.

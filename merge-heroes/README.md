# 합체 용사단

코인으로 근거리·원거리 용사를 따로 사고, 같은 용사 둘을 합체하며 도감을 채우는 별도의 어린이 게임입니다. 기존 `mix-heroes/` 게임과 URL·전투 규칙·저장이 분리됩니다.

## 플레이 주소

https://coolgary825.github.io/mini-games/merge-heroes/

로컬: 저장소 루트에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/merge-heroes/`를 엽니다. 정적 ES 모듈로 실행되며 빌드·계정·백엔드·외부 서비스가 필요 없습니다. 기존 게임에서 직접 제작한 SVG 원화와 공통 스타일 일부를 상대 경로로 공유합니다.

## 규칙

- 시작 선물: 코인 180개, 보석 20개, 새싹 기사 한 명.
- 근거리 기사: 50코인. 원거리 궁수: 60코인. 역할별 구매 버튼을 제공합니다.
- 일반 합체: 같은 종류·같은 단계 두 명 → 다음 단계 한 명. 무료이며 항상 성공합니다.
- 슈퍼 합체: 첫 번째로 고른 용사를 주인공으로 삼아 원하는 다른 용사와 합칩니다. 종류와 단계가 달라도 됩니다. 두 명을 소비해 주인공이 한 단계 성장합니다. 결과와 비용을 먼저 보여 주고, 버튼을 눌러야 소비합니다.
- 슈퍼 합체 비용: 주인공 1·2·3·4단계에 각각 80·160·320·640코인. 5단계는 최종 단계입니다.
- 용사 도감: 실제로 얻은 캐릭터의 이름, 역할, 단계, 최대 체력, 1회 공격력을 표시합니다. 합체·돌려보내기로 소유 인원이 줄어도 기록은 유지됩니다. 미획득 용사의 이름·능력치·구매는 잠겨 있습니다.
- 도감 구매: 이미 발견한 용사를 보석으로 다시 구매합니다. 1~5단계 비용은 각각 10·25·60·140·320보석입니다. 코인 잔액에는 영향을 주지 않습니다.
- 보석 획득: 웨이브 승리 시 `8 + 단계 × 2`, 5의 배수 보스전은 15개 추가. 처치 코인과 승리 코인은 별도입니다.

## 용사와 배치

근거리: 새싹 기사 → 방패 기사 → 강철 기사 → 불꽃 기사 → 태양 기사.

원거리: 새싹 궁수 → 숲의 궁수 → 바람 사수 → 별빛 사수 → 달빛 사수.

총 12명 중 6명이 전장에 배치되고 나머지는 대기합니다. 구입한 용사는 빈 전장 자리에 우선 배치됩니다. 한 명을 선택하고 ‘자리 옮기기’로 이동하거나 기존 용사와 자리를 교환합니다. 대기 용사는 전투에 참여하지 않습니다.

‘돌려보내기’는 별도 확인 후 기본 구입가 × 2^(단계−1) 코인을 지급합니다. 슈퍼 합체에 쓴 추가 비용은 포함하지 않습니다. 마지막 용사는 돌려보낼 수 없으며, 유일한 출전 용사를 돌려보내면 대기 용사를 자동 배치해 진행이 막히지 않게 합니다.

## 전투와 저장

20개 웨이브, 5·10·15·20단계 보스전입니다. 전투는 자동이며 구매·합체·배치는 전투 전 준비 시간에 합니다. 속도 1×/2×, 멈춤, 음소거, 터치, 키보드 버튼 조작을 지원합니다. Space는 일반 화면에서 시작·멈춤입니다. 도감이나 도움말을 열거나 탭을 떠나면 전투가 멈춥니다.

전투 승리 시 다음 전투에서 체력과 숲의 보석을 회복합니다. 패배·재도전·전투 중 새로고침은 코인, 보석, 용사, 도감을 전투 직전 체크포인트로 복구합니다. 승리 보상은 재접속으로 중복 지급되지 않습니다. 최종 승리 뒤에도 합체와 도감 구매는 가능합니다.

저장 키는 `junwoo-merge-heroes-v1`입니다. 기존 게임의 저장은 변경하지 않습니다. 새 모험은 코인·보석·용사단을 초기화하지만 발견한 도감은 유지합니다. 브라우저 저장 차단 시 현재 화면에서 게임을 진행할 수 있고, 잘못된 데이터는 초기 상태로 복구합니다.

## 소스와 검증

- `data.mjs`: 같은 캐릭터 데이터를 도감·상점·합체 미리보기·전투에서 공유합니다.
- `engine.mjs`: 재화, 일반·슈퍼 합체, 보석 구매, 발견 기록, 배치, 전투, 저장 검증.
- `art.mjs`, `render.mjs`: 단계별 외형, 캐릭터 애니메이션, 숲과 전투 연출.
- `game.mjs`, `index.html`, `style.css`: 클릭·터치 UI와 모달, 저장·효과음.

```sh
node --test merge-heroes/tests/engine.test.mjs
```

38개 검사는 두 전략·두 속도의 20단계 완주 및 10종 발견, 모든 일반 합체, 슈퍼 합체 단계별 비용·선택 순서·실패 원자성, 미획득 구매 금지, 10종 보석 구매, 도감과 실제 체력·공격력 일치, 배치·대기·돌려보내기, 재화·발견 기록 복구를 확인합니다.

```sh
MERGE_URL=http://localhost:8000/merge-heroes/ \
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
node merge-heroes/tests/browser.mjs
```

실제 크롬 UI에서 코인 구매, 일반 합체, 모바일 슈퍼 합체, 도감 잠금·수치·필터·보석 구매, 보석 부족, 승리 보상, 새로고침, 기존 저장 유지, 5·10·20단계 보스, 최종 승리 후 5단계 용사 구매, 화면 폭과 저장 차단을 검증합니다. 보스전 시작 상태는 테스트에서만 준비하며 실행 게임에는 자동 플레이가 없습니다.

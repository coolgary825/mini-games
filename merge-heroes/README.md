# 합체 용사단 · 가디언 작전

여름·가을·커피·모카·라떼·팝콘공·드래곤을 모으는 합체 전략 게임입니다. 갑옷과 장비를 갖춘 반려동물 용사, 금속 기지 네 구역, 서로 다른 적과 보스, 직접 누르는 전투 스킬을 제공합니다. 믹스 히어로즈와 규칙·저장은 별도입니다.

플레이: https://coolgary825.github.io/mini-games/merge-heroes/?v=20261005-ops1

정적 ES 모듈이며 빌드·계정·백엔드가 필요 없습니다. 저장소 루트에서 `python3 -m http.server 8000` 후 `/merge-heroes/`를 엽니다. 반려동물 원화만 `../rescue/art.mjs`에서 공유하며 장비·적·전장·아이콘은 이 폴더에서 제공합니다. 외부 이미지나 폰트를 요청하지 않습니다.

## 새 전투

- 궤도 정거장 → 붉은 협곡 → 번개 발전소 → 마지막 성채, 총 20라운드입니다. 구역마다 전장 색과 보스가 달라집니다.
- 정찰 드론, 코어로 달리는 돌격 드론, 총알 피해를 45% 줄이는 방패 골렘, 원거리 포격 드론, 보스가 서로 다른 방식으로 공격합니다. 후반에는 여러 적이 묶여 등장합니다.
- 보스는 5·10·15·20라운드에 등장합니다. 붉은 원에서 1.8초 동안 공격을 예고한 뒤 범위 피해를 줍니다. 두 번째 보스는 원거리 용사를 우선 겨냥하고, 세 번째부터 범위가 커지며, 마지막 보스는 체력이 절반 이하일 때 특수 공격이 빨라집니다. 충격파로 예고 공격을 취소할 수 있습니다.
- **과충전(Q)**: 에너지 40, 재사용 12초. 5초 동안 공격 속도가 80% 빨라집니다.
- **충격파(E)**: 에너지 55, 재사용 14초. 살아 있는 아군 공격력 합계의 115%로 적 전체를 공격하고 2초 기절시키며 보스 예고를 취소합니다.
- 에너지는 전투마다 50으로 시작해 초당 3, 적 처치마다 4씩 충전됩니다. 최대 100입니다. 코인과 보석은 쓰지 않습니다. 전투가 멈추면 스킬도 멈춥니다.
- 3성 이상 근거리는 네 번째 공격마다 주변 적에게 공격력 60%의 피해를 줍니다. 3성 이상 원거리는 총알로 1.5초 둔화를 걸고, 4성 이상 미사일은 주변에도 공격력 35%의 피해를 줍니다. 기본 공격력·체력과 특성은 도감에 표시됩니다.
- 라운드당 최대 별 3개: 클리어 1개, 코어 80 이상 1개, 75초 이내 전원 생존 1개. 별은 도전 기록이며 추가 재화를 주지 않습니다. 20라운드에 총 60개를 노릴 수 있습니다.

## 캐릭터와 합체

- 근거리 7종: 여름 → 커피 → 라떼 → 팝콘공 → 드래곤 → 번개 커피 → 태양 라떼.
- 원거리 7종: 가을 → 모카 → 별빛 가을 → 황금 모카 → 달빛 드래곤 → 로켓 팝콘공 → 은하 드래곤.
- 여름은 근거리, 가을은 원거리입니다. 공격 타입은 배치 위치로 바뀌지 않습니다. 원거리는 전투 중 제자리에서 총알·미사일을 쏘고, 근거리만 움직입니다. 아군과 겹쳐도 원거리는 밀려나지 않습니다.
- 일반 합체: 같은 타입·같은 별 단계 두 명 → 다음 단계 한 명. 무료, 100% 성공입니다.
- 슈퍼 합체: 다른 타입이나 단계의 친구도 두 번째 재료로 선택합니다. 첫 번째 친구의 타입으로 한 단계 성장하며 두 명을 소비합니다. ★1~6 비용은 80·160·280·440·650·900코인입니다. ★7은 최종 단계입니다.
- 도감에서는 이미 발견한 용사를 보석으로 구매합니다. ★1~7 가격은 10·25·60·140·320·650·1,200개입니다.
- 라떼는 장모 치와와, 커피는 검은 고양이, 모카는 노란 고양이입니다. 여름·가을은 크림색·갈색 고양이입니다.

## 경제와 배치

시작 자원은 180코인·20보석과 여름 한 명입니다. 여름은 50코인, 가을은 60코인입니다. 승리 코인은 `45 + 라운드 × 5`, 처치 코인은 정찰·돌격 2, 방패 4, 포격 3, 보스 15입니다. 20라운드 코인 공급은 시작 선물을 포함해 2,678개입니다. 승리 보석은 `8 + 라운드 × 2`, 보스전에는 15개를 더 줍니다.

적 체력은 `1.22^(라운드−1)`로 증가합니다. 적의 기본 공격은 해당 배율의 제곱근만큼 강해집니다. 후반에는 합체·도감 구매·스킬·배치를 활용해야 하며 한 용사에게만 투자하는 전략으로 쉽게 끝까지 갈 수 없습니다.

12명 중 6명이 전투하고 나머지는 대기합니다. ‘추천 배치’는 강한 용사 여섯 명을 골라 근거리는 앞, 원거리는 뒤부터 배치합니다. 개별 자리 이동과 교환도 가능합니다. ‘돌려보내기’는 확인 후 기본 구입가 × `2^(별−1)`의 50%를 돌려줍니다. 마지막 용사는 돌려보낼 수 없고 도감 기록은 남습니다.

## 화면과 저장

모바일 하단은 전투·용사/합체·도감입니다. 전투 화면에는 경기장과 두 스킬을 크게 표시하고, 관리 화면에서 모집·합체·배치를 합니다. 합체할 두 명을 고르면 합체 버튼으로 이동합니다. PC에서는 전장·모집·용사단·합체를 함께 표시합니다. 클릭·터치로 모든 기능을 쓸 수 있습니다. Space는 시작·멈춤, Q/E는 스킬이며 대화상자 안에서는 단축키가 작동하지 않습니다.

저장 키는 `junwoo-merge-heroes-v1`입니다. 이전 저장의 재화·도감·용사단·진행은 유지합니다. 새로 추가된 별 기록만 0부터 시작합니다. 이미 클리어했다면 ‘새 작전 시작 · 도감 유지’에서 확인 후 새 난이도를 시작합니다. 도감은 남고 팀·재화·진행·별 기록은 새 모험 기준으로 돌아갑니다.

승리 보상은 한 번만 지급합니다. 패배·재도전·전투 중 새로고침은 전투 직전 코인·보석·용사단·도감·별 기록을 복구합니다. 다음 라운드에는 체력과 코어를 회복합니다. 최종 승리 후에도 합체와 도감 구매가 가능합니다. 저장 차단 환경에서도 현재 화면에서 플레이할 수 있습니다.

# 합체 용사단 · 스타 아레나

여름·가을·커피·모카·라떼·팝콘공·드래곤을 모으는 어린이 합체 게임입니다. 네온 우주 경기장, 총알과 미사일, 7성 성장과 도감을 제공합니다. 기존 믹스 히어로즈와 화면 스타일·규칙·저장을 분리합니다.

플레이: https://coolgary825.github.io/mini-games/merge-heroes/

정적 ES 모듈로 실행하며 빌드·계정·백엔드가 필요 없습니다. 저장소 루트에서 `python3 -m http.server 8000` 후 `/merge-heroes/`를 엽니다. 반려동물 원화만 `../rescue/art.mjs`에서 공유하고, 스타일·아이콘·적·전장 아트는 이 게임 폴더에서 제공합니다.

## 캐릭터와 합체

- 근거리 7종: 여름 → 커피 → 라떼 → 팝콘공 → 드래곤 → 번개 커피 → 태양 라떼.
- 원거리 7종: 가을 → 모카 → 별빛 가을 → 황금 모카 → 달빛 드래곤 → 로켓 팝콘공 → 은하 드래곤.
- 공격 타입은 캐릭터에 고정됩니다. 여섯 배치 칸은 공격 타입을 변경하지 않습니다. 근거리는 적에게 다가가 공격하고, 원거리는 배치 위치에 고정되어 1~3성 장난감 블래스터, 4~7성 미사일을 발사합니다. 원거리 사거리는 780으로 모든 배치 칸에서 입구의 적을 공격할 수 있습니다. 아군과 겹쳐도 원거리는 밀려나지 않으며, 근거리만 비켜 움직입니다.
- 일반 합체: 같은 타입·같은 별 단계 두 명 → 다음 단계 한 명. 무료이며 100% 성공합니다.
- 슈퍼 합체: 타입·단계가 다른 친구도 두 번째 재료로 고를 수 있습니다. 첫 번째 친구의 타입으로 한 단계 성장하며 두 명을 소비합니다. 미리보기와 비용을 확인한 뒤 합체 버튼을 누릅니다.
- 슈퍼 비용: 주인공 ★1~6에 각각 80·160·280·440·650·900코인. ★7은 최종 단계입니다.
- 라떼는 장모 치와와, 커피는 검은 고양이, 모카는 노란 고양이입니다. 여름·가을은 기존 구조대 원화의 크림색·갈색을 사용합니다.

## 경제와 난이도

- 시작: 180코인, 20보석, 근거리 여름 한 마리.
- 별도 구매: 여름 50코인 / 가을 60코인.
- 승리 코인: `45 + 라운드 × 5`. 적 처치: 일반·빠른 젤리 2, 튼튼한 젤리 4, 보스 15코인.
- 새 모험의 전체 코인 공급은 시작 선물 포함 2,626개입니다. 기존 승리 보상 `70 + 라운드 × 8`과 처치 보상 6·6·9·35보다 줄였습니다.
- 적 체력 배율은 `1.18^(라운드−1)`입니다. 총 20라운드이며 5·10·15·20은 보스전입니다. 후반에는 보석 구매와 합체를 활용해야 합니다.
- 승리 보석: `8 + 라운드 × 2`, 보스전 15개 추가.
- 발견한 친구는 도감에서 보석으로 다시 구매합니다. ★1~7 비용은 10·25·60·140·320·650·1,200보석입니다. 이름, 고정 타입, 최대 체력, 공격력은 실제 전투 데이터와 같습니다.
- ‘돌려보내기’는 별도 확인 후 기본 구입가 × `2^(별−1)`의 50%를 지급합니다. 마지막 친구는 돌려보낼 수 없습니다. 발견 기록은 남습니다.

## 배치와 저장

12명 중 6명이 전장에 배치되며 나머지는 대기합니다. ‘자리 옮기기’로 빈칸 이동이나 친구끼리 교환이 가능합니다. 전투 중에는 구매·합체·배치를 할 수 없습니다. 1×/2× 속도, 일시 정지, 소리, 터치·키보드 버튼 조작을 지원합니다. Space로 시작·멈춤이 가능합니다.

저장 키 `junwoo-merge-heroes-v1`, 역할·단계 키를 유지합니다. 이전 5성 저장의 재화·도감·배치·진행은 유지되며 해당 역할·단계의 새 캐릭터로 표시됩니다. 이미 클리어한 경우 ‘새 모험 시작’으로 새 난이도를 플레이합니다. 재시작은 도감만 유지하고 재화와 용사단은 초기화하며 확인창이 있습니다.

승리 보상은 한 번만 지급합니다. 패배·재도전·전투 중 새로고침은 전투 직전 코인·보석·용사단·도감을 복구합니다. 다음 라운드에는 체력과 코어를 회복합니다. 최종 승리 후에도 합체와 도감 구매를 할 수 있습니다. 저장 차단 시 현재 화면에서 진행할 수 있으며 손상된 저장은 초기 상태로 복구합니다.

## 검증

```sh
node --test merge-heroes/tests/engine.test.mjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
MERGE_URL=http://localhost:8000/merge-heroes/ \
node merge-heroes/tests/browser.mjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
node merge-heroes/tests/ranged.browser.mjs
```

엔진 검사는 두 전략·두 속도의 20라운드 완주, ★7 도달, 14종 실제 능력치, 모든 단계 합체·보석 구매, 여섯 배치 위치의 공격 타입 불변과 원거리 고정 위치·입구 사격·명중, 총알·미사일, 재화 감소, 기존 5성 저장 호환, 실패 시 소비 방지를 확인합니다. 일반 합체 전략의 최종 보스 준비에는 도감 구매를 사용합니다. 브라우저 검사는 PC·모바일 구매·합체·이동·도감·보상·저장, 보스전, 7성 구매와 좁은 화면 배치를 확인합니다.

원거리 브라우저 검사는 PC·모바일에서 총알·미사일 캐릭터의 실제 캔버스 위치가 고정된 채로 적을 처치하는지 확인합니다.

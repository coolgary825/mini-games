# 준우네 3D 체스 클럽

정적 웹 앱. 상위 디렉터리에서 `python3 -m http.server 8765`를 실행하고 `/chess/`를 열면 됩니다. 외부 CDN을 런타임에 사용하지 않으며, HTTPS 또는 localhost에서 첫 캐시가 끝나면 오프라인으로 동작합니다.

## 기능

- 실제 Three.js 3D 보드, 회전·확대·카메라 초기화, 2D 전환 및 WebGL 실패 시 자동 전환
- 6종 기물별 이동·포획 퇴장·승리 애니메이션, 캐슬링 동시 이동, 승급 효과, 동작 줄이기 지원
- Stockfish 18 Lite, 8단계 상대적 난이도 (공식 Elo 수치가 아님)
- AI 백/흑/랜덤 대전, 같은 기기 2인 대전
- 무제한 및 3+2 / 5+3 / 10+5 / 15+10 시계, 일시정지
- chess.js 규칙: 체크, 체크메이트, 캐슬링, 앙파상, 선택 승급, 스테일메이트, 반복, 50수, 기물 부족
- 자동 저장과 이어 두기, 가족별 전적·퍼즐 진도
- 추천 수 화살표, AI 평가, 코치, 합법 이동 표시, 무르기
- 8개 한 수 메이트 퍼즐 (모든 합법적인 메이트 정답 인정)
- 클릭 가능한 기보 복기, PGN 저장/불러오기, FEN 불러오기/복사
- 테마 4종, 효과음, 전체 화면, 키보드, PWA

캐주얼 시계 정책: 첫 수 이후 시작, 화면을 떠나거나 복기 시 정지, 애니메이션 시간 제외. 타임아웃 시 상대 킹만 남거나 전체 기물이 부족한 경우 무승부. FIDE 대회용 시계·클레임 UI를 표방하지 않습니다. 무르기·힌트 사용, 불러온 기보는 전적에서 제외합니다. 다른 기기와의 계정 동기화나 온라인 멀티플레이는 없습니다.

`tests/domain.test.mjs`는 특별 규칙, 퍼즐 정답, 저장 왕복, 애니메이션별 특성과 모델을 검증합니다. `node --test chess/tests/domain.test.mjs`로 실행합니다. UI 회귀 검증은 외부 임시 디렉터리에 jsdom을 설치한 후 `JUNWOO_TEST_MODULES=/tmp/junwoo-chess-checks node --test chess/tests/runtime.test.mjs`로 실행합니다. 실제 Stockfish WASM과 모의 DOM을 사용하며 브라우저 화면 검증은 포함하지 않습니다.

# 커피 GO

실제 GPS 위치에서 커피·모카·라떼·가을·여름·오레오·팝콘공·드래곤·에스프레소를 발견하는 1인용 웹 게임입니다. 실제 OpenStreetMap 지도, 3D 캐릭터, 볼 투척, CP 강화, 여섯 동료의 레이드와 연구 보상을 제공합니다.

## 실행

공개 게임 주소: https://coolgary825.github.io/mini-games/coffee-go/

저장소 루트에서:

```sh
python3 -m http.server 8017
```

PC에서는 `http://localhost:8017/coffee-go/`를 엽니다. 휴대폰의 실제 GPS는 **HTTPS로 서비스되는 주소**에서 사용해야 합니다. 일반적인 PC LAN 주소의 HTTP 서버에서는 브라우저가 위치 기능을 허용하지 않습니다. GitHub Pages의 공개 주소는 HTTPS를 사용합니다.

‘모험 시작하기’ → 첫 동료 선택 → 위치 권한 허용 순서로 시작합니다. GPS 오차가 50m 이하이고 30초 이내에 갱신된 위치에서 80m 이내의 개체와 상호작용할 수 있습니다. 위치를 못 찾는 동안에도 보관함·가방·도감·연구는 열립니다. 키보드로 위치를 이동시키는 기능은 없습니다.

## 조작

- 지도: 캐릭터를 눌러 포획, 주변 탐색 버튼으로 목록 확인, 보급소에서 기본볼 수령. 조준 모양 버튼은 현재 위치로 돌아옵니다.
- 포획: 화면 아래 볼을 누른 채 위로 밀어 던집니다. 조준 원이 작을 때 정확히 맞히면 Great / Excellent 보너스를 받습니다. 키보드 접근 시 볼에 초점을 맞추고 Enter 또는 Space로 기본 명중 던지기가 가능합니다.
- 보관함: CP순 보기, 종류 필터, 개체 상세 능력치와 별가루 강화.
- 레이드: 서로 다른 동료 여섯 마리를 고른 뒤 시작. 탭·공격 버튼으로 기본 공격, 에너지 100%에 필살기, 좌우 스와이프·회피 버튼으로 공격 회피. 쓰러지면 다음 동료가 출전합니다.
- 제한시간 180초. 패배해도 동료는 사라지지 않고 다음 전투에 회복됩니다. 승리하면 보상과 일반 CP의 보스 포획 기회가 생깁니다.

## 볼과 연구

시작 시 기본볼 30개, 슈퍼볼 5개이며 하이퍼·마스터볼은 없습니다. 기본볼 → 슈퍼볼 → 하이퍼볼 순으로 포획 확률이 높아지고, 마스터볼은 사용 확인 후 반드시 잡습니다. 일반 볼의 실제 확률은 개체 CP·희귀도·명중 등급에 따라 달라집니다.

| 연구 | 조건 | 보상 |
|---|---|---|
| 일일 | 5마리 포획 | 기본볼 10개 |
| 일일 정밀 | 15마리 포획, Great 이상 10회 | 슈퍼볼 5개 |
| 7일 고급 | 30마리 포획, 레이드 3승, Excellent 5회 | 하이퍼볼 3개 |
| 평생 한 번 특별 | 150마리 포획, 9종 발견, 레이드 15승, Excellent 30회 | 마스터볼 1개 |

보급소는 5분마다 기본볼 5개를 줍니다. 볼이 떨어져도 보급으로 재개할 수 있습니다. 희귀 볼은 보급소나 단순 출석으로 나오지 않습니다.

## 저장·위치·연결

`junwoo-coffee-go-v1` 키로 이 브라우저에 저장합니다. 다른 게임의 기록을 변경하지 않습니다. 브라우저 기록을 지우거나 다른 기기로 바꾸면 자동으로 이어지지 않습니다. 손상된 기록은 자동 덮어쓰지 않고 내려받기와 새 시작 선택을 제공합니다. 저장 공간이 막혔을 때는 경고하고 현재 메모리에서 계속 플레이합니다.

볼 소비와 포획 결과를 애니메이션 전에 함께 저장하며, 레이드 승리와 포획 기회도 함께 기록합니다. 전투 중 새로고침하면 전투만 종료되고 동료는 보존됩니다. 승리 후 새로고침하면 보스 포획으로 이어집니다.

연속 위치 경로는 저장하지 않습니다. 중복 포획 방지 ID에는 대략적인 지역 격자와 시간 구간이 포함됩니다. 지도 타일 요청은 지도 제공자에게 조회 지역을 드러냅니다. 실제 지도 연결이 실패하면 재연결 안내를 표시합니다. 지도는 인터넷 연결이 필요하고 오프라인 다운로드를 하지 않습니다. 레이드는 게임 속 가상 사건이며 다른 플레이어와 공유되는 실제 모임이 아닙니다.

## 검증

```sh
node --test coffee-go/tests/*.test.mjs
```

브라우저 검사는 `ego-browser`에서 진행합니다. `tests/fixture.html?case=team` 등은 분리된 세션 저장과 테스트 GPS(서울시청)를 주입하는 검증용 화면이며, 정식 `index.html`에는 위치 시뮬레이션이나 아이템 지급 기능이 없습니다. 케이스: `fresh`, `team`, `master`, `quests`, `empty`, `denied`, `inaccurate`, `corrupt`, `blocked`. 상태는 `coffee-go-test-<case>-<run>` 세션 키에만 저장합니다.

`tests/ui-checklist.md`와 `tests/acceptance.md`에 검증 항목과 결과를 기록합니다. 실제 야외에서 휴대폰을 들고 걸어다니는 검증은 자동화로 대체하지 않으며 별도로 필요합니다.

외부 라이브러리·지도 출처: [THIRD_PARTY.md](THIRD_PARTY.md).

`tests/browser-regressions.mjs`는 기존 ego-browser 페이지를 받아 주변 개체 갱신, 여섯 마리 선택, 가로 화면 버튼, 날짜 변경을 검사합니다. `?run=고유값`으로 테스트 상태를 분리할 수 있습니다.

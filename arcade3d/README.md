# 준우네 3D 게임 월드

다섯 게임의 새로운 독립 3D 모드입니다. 실제 Three.js 메시·조명·그림자·카메라·월드 좌표 충돌을 사용합니다. 원래 HTML 게임과 저장 키는 유지하며, 각 3D 게임 안의 **기존 게임 이어하기**로 접근합니다.

| 게임 | 3D 모드 | 새 플레이 |
|---|---|---|
| 미니 로블록스 | `../roblox/3d.html` | 26개 하늘 발판, 움직이는 발판, 체크포인트, 코인 러시, 메테오 생존, 이중 점프·대시·속도 강화 |
| 몬스터 디펜스 | `../defense/3d.html` | 화살·대포·서리·번개 타워, 3단계 강화, 판매, 20 웨이브, 매 5웨이브 보스, 2배속, 유성 궁극기 |
| 브레인롯 훔치기 | `../brainrot/3d.html` | 경비 추적, 운반과 보관, 10칸 기지, 자동 수익, 속도·보호막 강화, 여우 경호원, 환생 |

## 조작과 저장

액션 게임은 WASD/방향키 또는 터치 조이스틱, 바닥 터치로 이동합니다. 행동 버튼과 단축키가 화면에 표시됩니다. 디펜스는 원형 건설 칸을 선택해 타워를 세우고, 공주게임은 옷장과 모드 메뉴로 조작합니다. 두 게임의 카메라는 드래그로 회전할 수 있습니다.

`junwoo-3d-게임ID-플레이어` 키로 별도 3D 진행을 저장합니다. 기존 게임의 저장 데이터는 읽거나 수정하지 않습니다. 99나이트는 아침과 건설/구조 시 탐험을 저장합니다. 나머지 게임은 코인·컬렉션·꾸미기·최고 기록을 저장하고 라운드는 새로 시작합니다. 다른 창으로 이동하면 일시정지합니다. 프로필은 이 브라우저 안에서만 동작하며 온라인 계정이 아닙니다.

화질: 선명하게/가볍게, 효과음, 전체 화면, 난이도 3단계를 지원합니다. WebGL을 지원하지 않는 환경에는 기존 게임 링크를 표시합니다. 코인·하트는 게임 내 점수이며 구매나 결제 기능은 없습니다.

## 개발과 검증

게임 모음 루트에서 `python3 -m http.server 8765`로 실행하고 위 경로를 엽니다. 앱은 CDN을 사용하지 않습니다. Three.js 0.180.0은 기존 체스의 로컬 vendor 디렉터리에서 재사용합니다.

`node --test arcade3d/tests/games.test.mjs`는 실제 3D 장면과 게임 로직을 WebGL 없이 구동하여 이동·충돌·경제·전투·저장·심사를 검증합니다. UI 테스트에는 외부에 설치한 jsdom이 필요합니다. 브라우저 GPU 화면을 검증하는 테스트와는 구분됩니다.

게임별 서비스워커는 각 게임의 캐시만 정리하고 3D 경로·관련 모듈을 캐시합니다. 변경할 때 CACHE 버전을 올려 주세요.
